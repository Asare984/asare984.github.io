Week 1 — What Is an Information System?

An information system combines technology, people and process to collect, store, organise and share data.

Key points

  • Information systems: complementary networks of hardware and software that people and organisations use to collect, filter, process, create and distribute data.
  • Components: technology (hardware and software), data, people and process. A process is a series of steps to achieve a desired outcome.
  • Mainframe era (late 1950s to 1960s): large machines for calculation. MRP systems appeared in the late 1960s.
  • PC revolution: the Altair 8800 (1975), then Microsoft Windows made PCs easier to use.
  • Client-server (mid-1980s): computers connected to share resources. The first ERP systems ran on this model.
  • World Wide Web and e-commerce: the Internet began in 1969; Tim Berners-Lee developed the Web in 1989. Late 1990s brought the dot-com boom.
  • Web 2.0: collaboration and sharing, such as blogs and social networks.
  • Post-PC world, cloud computing and the Internet of Things (a network of interconnected physical devices) are the latest eras.

Week 2 — Hardware

Hardware is the physical equipment used for input, processing, output and storage.

Key points

  • CPU: the brain of the computer, made of the control unit and arithmetic logic unit. Speed is measured in GHz.
  • Primary storage (main memory) holds data being processed for short periods: registers (smallest), cache and RAM. It is volatile.
  • Secondary storage holds large amounts of data for long periods. It is nonvolatile, slower than RAM and cheaper.
  • Storage units: a byte is 8 bits, then kilobyte, megabyte, gigabyte and so on.
  • Peripherals are auxiliary devices such as a mouse or keyboard.
  • Computing devices: personal computers, portable computers (laptops, notebooks, netbooks), smartphones and tablets.
  • Trends: miniaturisation and portability, cloud computing, and the Internet of Things, a network of billions of devices with unique addresses.

Week 2 — Software

Software is the set of instructions that make the hardware useful.

Key points

  • Operating system: manages hardware resources, provides the user interface, and manages files and applications.
  • Application software performs specific tasks. Productivity software includes word processing, spreadsheets and presentations.
  • Utility software looks after the computer. Programming software is used to produce other software.
  • Network operating system: runs on a server to manage data, users, groups and security. Advantages: stable and centralised. Disadvantage: high cost.
  • ERP: enterprise software bringing an organisation's information under centralised control.
  • Cloud computing: applications and storage on the Internet. Advantage: nothing to install. Disadvantage: data is on someone else's server.
  • Virtualisation uses software to simulate a computer. Open-source software makes the source code available to all.
  • Malware: a virus spreads from device to device; a worm usually spreads without user action. Protect with antivirus, a firewall and updates.
  • Piracy is copying software without permission. Companies copyright software to protect it.

Week 3 — Networking and Communication

Networks connect computers so that people and organisations can share data and communicate.

Key points

  • The Internet began with ARPANET after the 1957 launch of Sputnik. TCP/IP became the standard protocol.
  • Vocabulary: packet (unit of data), hub, switch (filters by destination), router, domain name.
  • Modem means modulator-demodulator. Broadband is at least 256,000 bits per second.
  • Wireless: Wi-Fi turns an Internet signal into radio waves; mobile networks; Bluetooth (created 1994); VoIP carries voice over the Internet.
  • LAN: local network in a building. WAN: covers a wide area.
  • Client-server: servers provide services to client computers.
  • Intranet: private network inside an enterprise. Extranet: private network opened securely to outsiders such as suppliers.
  • The Internet is a network of networks; the World Wide Web is one service that runs on it.

Week 4 — Types of Information Systems

Different levels of an organisation need different kinds of information systems.

Key points

  • Three levels: operational, management (tactical) and strategic.
  • Transaction processing system (TPS): records, processes and validates routine transactions, such as payroll and reservations. Online systems have a direct operator connection.
  • Management information system (MIS): provides routine reports to help middle managers monitor and control.
  • Decision support system (DSS): supports complex, non-routine decisions.
  • Executive information system (EIS): a special DSS for top-level decisions, showing key performance indicators.
  • Knowledge work systems (KWS) support knowledge workers. Office automation systems (OAS) raise the productivity of data workers.
  • Expert system: emulates a human expert in a narrow field. Components: knowledge base, inference engine, user interface.

Week 4 — Globalisation and the Digital Divide

Information technology has connected the world, but not everyone shares the benefits equally.

Key points

  • Globalisation: integration of goods, services and culture among nations.
  • Castells' network society: an economy able to work as a unit in real time on a planetary scale.
  • Friedman's The World Is Flat (2005): Globalisation 1.0 (1492 to about 1800, countries), 2.0 (companies), 3.0 (individuals).
  • Benefits to firms: expertise and labour around the world, new markets. Challenges: infrastructure differences, labour laws, legal requirements, cybersecurity.
  • Digital divide: the gap between those with access to technology and those without.
  • One Laptop per Child tried to close the gap; it faced cultural differences, corruption and competition.
  • Nielsen's three stages: economic (access), usability (skills) and empowerment divides. In levels: access and infrastructure, digital literacy, and quality and relevance of content.

Week 5 — Artificial Intelligence in Business and Academia

Artificial intelligence lets machines do tasks that normally need human intelligence.

Key points

  • The term AI was coined at Dartmouth in 1956. Early pioneers include Alan Turing.
  • AI winters (the first ran 1974 to 1980) were periods of reduced funding when goals proved too ambitious.
  • AI works by acquiring data and developing algorithms (step-by-step instructions).
  • Four types: reactive (no memory), limited memory, theory of mind (understands others' mental states) and self-aware (a concept).
  • Benefits: better and faster customer service, automation of tedious tasks, better decisions.
  • Risks: worker mistrust and fear of job loss, errors from poor data, ethical problems, higher costs.
  • AI is used in finance, legal work, healthcare and many other sectors. Global data is expected to reach 175 zettabytes by 2025.

Week 5 — Industrial Internet of Things (IIoT)

The Internet of Things connects everyday devices to the Internet. The industrial version links machines in factories and farms.

Key points

  • Industrial revolutions: 1st (1760s) steam and mechanisation; 2nd (1870s) electricity and mass production; 3rd (1960s) computers; 4th (now) hyper-connectivity.
  • Technologies behind the 4th revolution: AI, robotics, data analytics, IoT, virtual reality and more.
  • IoT examples: smart farming sensors, devices for the elderly (fall detection), smart toothbrush, smart egg tray.
  • Advantages: better customer engagement, technology optimisation, less waste, richer data.
  • Disadvantages: security, privacy, complexity and compliance.
  • Securing IoT: device authentication and network-enforced policies.

Week 7-8 — HTML Basics and CSS

HTML gives a web page its structure and CSS gives it its style.

Key points

  • HTML stands for Hyper Text Markup Language. House analogy: HTML is the structure, CSS the paint and furniture, JavaScript the electricity.
  • A page starts with the DOCTYPE declaration, then the html element containing head and body.
  • An element has a start tag, content and an end tag. Common tags: headings h1 to h6, p, a, img, ul, ol, li.
  • The a tag creates links with href. The img tag uses src and alt.
  • CSS (Cascading Style Sheets): a rule has a selector and a declaration block.
  • Three ways to add CSS: inline, internal (in a style element in the head) and external (a linked .css file).
  • Box model, from the inside out: content, padding, border, margin.
  • div is a block container, span is inline. Design principles: consistency, readability, simplicity, good colour contrast.
  • Common mistakes: missing closing tags, unclosed quotes, wrong file paths, CSS syntax errors.

Week 9-11 — JavaScript, Forms and the DOM

JavaScript adds behaviour to web pages, so they respond to users.

Key points

  • The web trinity: HTML (structure), CSS (presentation), JavaScript (behaviour).
  • JavaScript is a client-side scripting language that runs in the browser.
  • Add it inline, internally (script element) or externally (a .js file, recommended for larger projects).
  • Variables: let (can change), const (fixed), var (legacy). Data types include strings and numbers.
  • A function is a reusable block of code that runs when invoked.
  • The DOM (Document Object Model) represents the page as a tree so JavaScript can find and change elements.
  • Selecting elements: getElementById, querySelector, querySelectorAll. Changing content: innerHTML. Changing style: the style property.
  • Events (click, mouseover, submit, change) are handled with event listeners such as addEventListener.
  • Forms collect user input with the form element, input types and labels.

Week 10 — Google Forms Add-ons and Automation

Google Forms add-ons and automation platforms extend what a form can do.

Key points

  • Add-ons are third-party apps that integrate with Google Forms, found in the Google Workspace Marketplace.
  • Popular add-ons: Form Publisher (documents or PDFs from a template), email notifications, FormLimiter (closes a form by date or response count).
  • Free tiers have limits, for example a fixed number of documents per month.
  • Security: grant only minimal permissions and avoid risky ones.
  • Zapier and Make connect Forms to thousands of apps with 'if this then that' logic, for example a new response creating a Trello card or a Slack message.
  • Good automation needs a clear understanding of the business process and the right tool.
